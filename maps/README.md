# Carte et confidentialité

`manifest.json` décrit une méthode et quatre zones candidates, pas un monde inventé.
Les dossiers de monde réels sont générés dans `runtime/` et exclus de Git.

Aucun château, mur défensif, salle ou objectif n'est fourni. Les quatre territoires
doivent être inspectés puis définis en jeu. Les objectifs sont posés et cachés par les
équipes pendant la préparation. Ne jamais copier leur fichier d'état dans ce dossier.

Consulter [le guide de carte](../docs/MAP_GUIDE.md) pour prégénérer, importer et contrôler
les terrains. La génération vanilla conserve quelques structures naturelles ; il
faut sélectionner les territoires pour ne pas donner une forteresse ou un village
défendable à une seule équipe.
